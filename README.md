# Qt To-Do List App

A desktop task management application built with **C++, Qt 6, Qt Widgets, and CMake**.

## Features

- Add new tasks
- Validate empty task input
- Mark tasks as completed using checkboxes
- Strike through completed tasks
- Delete checked tasks
- Display total, completed, and remaining task counts
- Save tasks to a file and restore them when the application restarts
- Dark-themed user interface

## Technologies Used

- C++
- Qt 6
- Qt Widgets
- Qt Designer
- CMake

## How to Run

1. Install Qt 6 and a compatible C++ compiler.
2. Open the project in Qt Creator.
3. Open `CMakeLists.txt` as a project.
4. Configure the project using an available kit.
5. Build and run the application.
